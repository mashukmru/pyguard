ABOUT THE PROJECT

Network security,
made inspectable.

PyGuard is a Python-based firewall and network monitoring toolkit for people who want to understand how traffic filtering works and see activity in a practical dashboard.

Visibility with control

Packet capture is started explicitly from the dashboard and depends on Scapy and the host's capture support. When running, traffic is processed by configurable rules and rate limiting, with events recorded as structured logs.

The web dashboard brings together firewall status, rule management, geo rules, rule testing, local simulations and log review. It presents the state reported by the application and keeps capture under the operator's control.
